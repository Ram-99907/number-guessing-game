# Number Guessing Game in C

## Description
This is a simple Numberr Guessing Game developed using C language.
The program generates a random number it  and allows the user to guess it.
The game provides hints if the guessed number is too high or too low.

## Features
- Generates random number
- User-friendly menu
- Counts number of attempts
- Gives hints (High / Low)

## Sample Output
Guess the number between 1 and 100
Enter your guess: 07
Too low! Try again.

Enter your guess: 72
Too high! Try again.

Enter your guess: 60
Congratulations! You guessed the number in 34 attempts.
